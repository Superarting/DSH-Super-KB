# DSH-Super-KB

DeepSeek Harness 的知识库面板：不离开应用即可浏览并检索知识文件夹，并让智能体在对话中直接查询这些文档。

## 功能

- 左侧边栏新增**知识库**图标，点击打开面板。
- **首次使用**显示来源配置向导：选择**本地文件夹**（系统原生目录选择器）或 **WebDAV 云盘**（地址、账号、密码、连接测试）。来源可随时在面板的"来源"视图中新增、修改、删除。
- **浏览**：左侧懒加载文件树，右侧文本/Markdown 预览。
- **搜索**：跨全部来源的大小写不敏感全文搜索，返回文件、行号与上下文片段。
- **智能体工具**：`kb_search`（关键词）、`kb_read`（来源、路径）、`kb_list`（来源、路径?），模型可在任何对话中直接检索你的文档。

## 来源类型

| 类型 | 字段 | 说明 |
|---|---|---|
| 本地文件夹 | 绝对路径 | 只读；每次读取都会解析路径并限制在所配置根目录内。 |
| WebDAV | 地址、用户名、密码、可选基础路径 | 只读（PROPFIND/GET）。密码存入凭据记录，绝不写入配置文件。 |

来源持久保存在插件配置中，重启与升级后仍然有效。

## 三档记忆系统

面板头部「记忆」按钮进入记忆管理视图。记忆以带 frontmatter 的 Markdown 存放在第一个本地来源的 `DSH记忆/` 目录内，随知识库一起被 `kb_search` 检索：

| 档位 | 目录 | 可见范围 |
|---|---|---|
| 全局 | `global/` | 所有会话 |
| 工作区 | `workspaces/<cwd 哈希>/` | 仅该工作区（原路径存于 frontmatter `cwd`） |
| 会话 | `sessions/<id>/` | 仅该会话 |
| WorkBuddy | `workbuddy/` | 导入的只读副本 |

**智能体工具**：`memory_save`（保存；相似门控）、`memory_search`（BM25 检索，关键词三倍加权，默认隐藏已被取代条目）、`memory_read`、`memory_delete`、`memory_export`、`memory_restore`。

**注入**：系统提示词只注入「标题 + 关键词 + 路径」的有界索引（默认 ≤1500 字符，按更新时间排序），正文按需读取，避免 token 膨胀与 WorkBuddy 式的静默截断。

**写入门控**：保存时对现有记忆做相似度比较（Jaccard，阈值默认 0.7）；相似条目存在时返回提示，要求显式确认更新，防止碎片化膨胀。

**冲突消解**：矛盾更新通过 `supersedes` / `superseded-by` 链取代旧条目而不删除——召回默认取最新，历史可溯。

**快照**：导入、导出等批量操作前自动写入 `.snapshots/<时间戳>.json`（文件清单 + SHA256），UI 可随时校验；保留最近 20 份。

## WorkBuddy 记忆桥

- **导入**：读取 `~/.workbuddy/user-*-personal/*.md` 与 `memory/*.md`，转为只读副本存入 `workbuddy/` 子目录。SOUL/IDENTITY/USER 等身份文件永不修改。
- **导出**：DSH 记忆写入 `~/.workbuddy/memory/dsh-export/`，**只新增文件**，采用 sharding 约定（第 2 行为 keywords 行），可被社区 hook 召回方案直接使用；绝不改写 MEMORY.md。
- **设置**：插件配置 `memory.workbuddy.enabled` 与 `memory.workbuddy.direction`（import / export / both）可关闭或限定方向。

## 导出

「导出」支持把勾选档位的全部记忆复制到任一绝对路径（时间戳子目录，不覆盖），或选择 **WorkBuddy 分片格式**让导出文件直接兼容 WorkBuddy 记忆治理方案。

## 限制

- 2 MiB 以内的文本文件可预览和搜索；更大的文件只列出内容不读取。
- 搜索遍历文本类文件（md/txt/csv/json/xml/yaml 及源代码），单次运行有文件数与时间预算。
- WebDAV 搜索需要在线逐个拉取候选文件，大库较慢，界面会显示进度。
- 知识库文件与记忆写入仅发生在本地来源；WebDAV 来源保持只读。
- WorkBuddy 导入副本是快照而非实时同步；源文件变化需重新导入。

## 安全

- 所有 HTTP 路由挂在 `/api/` 下，处于连接层认证围栏之内：只有已认证的 owner Peer 可达。
- 本地读取有路径围栏：请求路径必须解析后仍位于来源根目录内，否则拒绝。
- WebDAV 密码进入凭据存储，不进入 profile 配置。
- 记忆读写同样受根目录围栏约束；`.snapshots/` 由插件管理，不可通过删除接口移除。
