# DSH-Super-KB 交互体验走查报告

走查方式：Playwright 拟真操作（打开面板 → 树展开/折叠 → 预览 → 搜索 → 新建/行菜单/重命名/删除确认 → 侧栏拖拽 → 键盘检查），证据截图在 `/tmp/kb-ux-shots/`，原始观察 `/tmp/kb-ux-observations.json`。

## 做得好的（保持）

- 弹层统一支持 **Esc 关闭**；删除用**自定义确认弹层**（非原生 confirm）
- 树**展开状态在刷新/操作后保留**（refresh 只软刷不重挂）
- 长文件名 ellipsis 截断；搜索结果带路径、关键词高亮、命中数与截断提示
- 侧栏可拖拽（240→480px）；预览/文本(代码) 双视图区分清晰

## P0 — 立即修（高频痛点）

### 1. 返回按钮在底部，长文档要滚回底部才能退出预览
**证据**：PDF/长 MD 预览时，返回按钮在 `.kb-surface-foot`（页面最底）。
**建议**：返回按钮移到顶部工具栏左侧（`‹` + 面包屑），底部 foot 保留或移除。附带在预览区支持 `Esc` 返回上一级。

### 2. 预览无路径/面包屑，深层文件"迷路"
**证据**：工具栏只有文件名（`钉钉视觉规范手册.pdf`），不知在哪层，也不能跳到同级。
**建议**：工具栏显示 `来源名 / 父目录 / 文件名` 分段面包屑；点父目录名返回该文件夹。数据已在 `activeFile.path`，纯前端改动。

### 3. 预览工具栏无任何操作，所有动作都要回树里找 ⋯
**证据**：预览态下"添加到任务/重命名/复制链接/打开文件夹/删除"全部缺席。
**建议**：预览工具栏右侧加一个 ⋯ 按钮，复用 `MoreMenu` 组件（同一条 path 传入即可）。

## P1 — 下一版本（体验跃升）

### 4. 搜索必须回车，且跳转后搜索状态丢失
**证据**：回车触发（无防抖即时搜索）；点命中进预览后，回搜索 tab 结果重置为 idle，需再回车。
**建议**：①输入 300ms 防抖即时搜索（保留回车立即触发）；②把 `searchQuery/searchTick/结果` 状态提升到 `KnowledgePanel`，或在 `SearchView` 加 `keepAlive`——切走再回来结果还在。

### 5. 树无键盘导航
**证据**：行有 `tabindex=0` 但无 ↑↓ 移动、Enter 展开/打开、→← 折叠/展开、首字母跳转。
**建议**：在 TreeRow 容器上监听 ArrowUp/Down/Left/Right/Enter（参照 ARIA tree pattern），焦点环用 `:focus-visible`。

### 6. 侧栏拖拽把手不可发现
**证据**：把手仅 5px 宽、无视觉元素，只有 hover 到才有 col-resize 光标。
**建议**：把手中央画一条 2×24px 竖条（hover 时高亮），命中区扩到 8px；双击把手恢复 240px 默认宽。

### 7. 重命名/新建为弹层输入，不是行内编辑
**证据**：重命名要开弹层→输入→回车（3 步）；`test.js` 之类场景高频。
**建议**：重命名改为**树行内编辑**（双击或 F2 进入，input 替换名称，Esc 取消/Enter 提交）；弹层保留给"新建"。

### 8. 删除无软删除
**证据**：删除直接落盘，不可撤销（确认弹层只是提示）。
**建议**：删除先移入来源根的 `.trash/`（隐藏目录已有过滤逻辑），行菜单加"最近删除"；或至少删除后 toast 内提供 5 秒"撤销"按钮。

## P2 — 锦上添花

### 9. 大目录无虚拟滚动
66 行尚可，千级文件目录会明显卡顿。建议行数 >300 时启用虚拟列表（react-window 或自写 5 行的窗口化）。

### 10. 无排序与过滤
固定按名称排序（文件夹优先）。建议工具栏加排序菜单（名称/修改时间/类型）+ 树顶部过滤输入框（输入即筛，客户端过滤已加载节点）。

### 11. 无多选批量操作
行菜单单文件粒度。建议 Ctrl/Cmd+点选多行 → 批量移动/删除/添加到任务。

### 12. Markdown 预览无 TOC、图片无缩放
长 MD 建议 `position:sticky` 右侧标题目录；图片预览加点击放大（lightbox）+ 复制按钮。

### 13. 无"最近打开/固定收藏"
面板重开总是从根浏览。建议本地记录最近 10 个预览文件，面板顶部 quick chips 一键回跳。

### 14. 外部拖放上传未接
把 Finder 文件拖进树区域应触发上传（现在无 drop 处理）。Upload/Import 菜单已有 file input，补 `dragover/drop` 即可复用。

## 建议实施顺序

| 批次 | 内容 | 工作量 |
|---|---|---|
| 第一批 | #1 返回按钮上移 + #2 面包屑 + #3 预览 ⋯ 菜单（同属预览工具栏重构，一次做完） | ~半天 |
| 第二批 | #4 搜索防抖+状态保持 + #6 拖拽把手可视化 | ~半天 |
| 第三批 | #5 键盘导航 + #7 行内重命名 | ~1 天 |
| 第四批 | #8 软删除 → 其余 P2 按需 | 按需 |

> #1–#3 同处预览工具栏，合并为一次改造收益最大；#4、#6 是小改动大感知；#5/#7 涉及交互模型，放后面稳妥。
